# 🎨 카드 스튜디오 (Card Studio)

> **"다양한 이미지와 문구를 안전하게 다루고, 미리보기·내려받기·사용자 템플릿을 실제 데이터로 일치시킵니다."**

## 📌 프로젝트 소개
**카드 스튜디오**는 웹 브라우저에서 로그인 없이 바로 사용할 수 있는 카드 뉴스/썸네일 편집기입니다. 
텍스트와 이미지를 레이어로 자유롭게 배치하고, 6가지 화면비에 맞춰 디자인한 뒤 고화질 PNG로 다운로드할 수 있습니다. 만든 디자인은 템플릿으로 저장하거나 JSON 파일로 백업할 수 있습니다.

## ✨ 주요 기능
- **다중 레이어 편집**: 텍스트와 이미지를 레이어로 자유롭게 추가, 삭제, 순서 변경(드래그 앤 드롭)
- **직관적인 캔버스 조작**: 8방향 핸들과 회전 아이콘으로 크기 및 각도 조절
- **이미지 편집 도구**: 밝기, 대비, 채도, 색조 조절 및 4방향 자르기(Crop) 지원
- **다양한 화면비**: 1:1, 4:5, 9:16, 16:9, 1.91:1, 3:4 지원
- **실행 취소 / 다시 실행**: `Ctrl+Z`, `Ctrl+Shift+Z` 단축키 및 UI 버튼 지원
- **템플릿 관리**: 현재 디자인을 새 템플릿으로 저장, 덮어쓰기, 이름 변경, 삭제
- **JSON 백업/복원**: 데이터를 JSON 파일로 내보내고 가져오기 (정교한 유효성 검사 포함)
- **안전한 데이터 처리**: 이미지는 Data URL로 변환 후 용량 최적화(1600px)하여 새로고침 후에도 깨지지 않음

## ✅ 짧은 확인 방법 (T03-C31)

- **① 어디로 가나요?**: `https://아이디.github.io/저장소이름/` (새 시크릿 창)
- **② 3단계 이내 무엇을 하나요?**: 
  1. 첫 화면 좌측에서 `🖼️ 사진 추가` 버튼 클릭
  2. 캔버스에서 사진을 드래그하여 배치하거나 텍스트를 입력
  3. 우측 하단 `PNG 저장` 버튼 클릭
- **③ 무엇이 보이면 통과인가요?**: 다운로드된 PNG 파일을 열었을 때, 화면에 보이는 글씨의 위치, 크기, 줄바꿈이 1픽셀도 틀리지 않고 똑같이 저장되어 있음
- **④ 안 될 때 무엇이 보이나요?**: `.txt` 파일을 캔버스에 끌어다 놓으면 `"파일명" 파일은 지원하지 않는 형식입니다.`라는 알림이 뜨고, 기존 편집 화면은 그대로 유지됨

## 🤖 AI와 나의 판단 (T03-C32)

- **① AI에게 맡긴 일**: 
  - 8방향 리사이즈 및 회전을 위한 캔버스 좌표 계산식(삼각함수), 레이어 데이터(JSON) 구조 설계, 드래그 앤 드롭 파일 처리 로직 구현
- **② 학생이 직접 판단한 일**: 
  - 미리보기와 다운로드 파일의 1:1 일치를 보장하기 위해 '화면 그리기'와 '파일 저장'이 완전히 동일한 `renderCard()` 함수를 쓰도록 아키텍처를 통일한 결정
- **③ AI 제안을 따르지 않은 일**: 
  - AI가 처음 제안했던 CSS(HTML 태그) 기반의 텍스트 미리보기를 과감히 거부함. (이유: 브라우저마다 폰트 렌더링과 줄바꿈 계산 방식이 달라서 다운로드한 이미지와 화면의 글자 위치가 어긋날 위험이 크기 때문)

## 🛡️ 공개 안전성 확인 (T03-C28 ~ C30)
- **위치 정보(EXIF) 0건**: Canvas API로 재인코딩하여 저장하므로 이미지의 메타데이터(위치정보 등)가 남지 않습니다.
- **개인정보 0건**: 화면 및 제출물에 개인 식별 정보가 포함되어 있지 않습니다.
- **비밀값 0건**: 코드(HTML/CSS/JS) 및 배포 파일에 API 키, 비밀번호 등이 포함되어 있지 않습니다.
